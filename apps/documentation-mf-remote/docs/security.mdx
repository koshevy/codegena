Do not include credentials or private specifications in a public issue.

## Dependency checks

Codegena checks runtime and development dependencies with its audit CLI. New vulnerable dependencies are rejected. Existing unpatchable findings require a documented, time-limited exception.

## Reporting a vulnerability

Use the repository's private security reporting channel when available. Avoid publishing exploit details before maintainers can assess the report.

See [Codegena on GitHub](https://github.com/koshevy/codegena) for the current reporting options.
