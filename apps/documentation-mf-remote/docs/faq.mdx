## Does generation need an AI model?

No. Schema conversion is deterministic. An AI assistant can operate the CLI, but generation does not require a model.

## Can Codegena run in a browser?

Yes. Playground performs schema conversion and search in the browser. The CLI is available for local development and automation.

## Can I change generated output?

Use generator options, templates, or visitors for repeatable changes. Editing generated files directly makes regeneration harder to manage.
