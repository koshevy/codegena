Read the repository's contribution guide and code style before changing a package. Find the owning Nx project and read its architecture decisions.

## Verify a change

Run the affected project's tests, lint, and build targets. UI changes also need coverage in the related E2E project. Run the dependency audit before submitting.

Report a reproducible issue in the [repository](https://github.com/koshevy/codegena/issues), including the smallest specification that demonstrates it.
