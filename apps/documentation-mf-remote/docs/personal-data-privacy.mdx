## Browser storage

The documentation stores your theme preference in browser local storage. Clearing this site's storage removes that preference.

## External services

Following a GitHub or social link opens another service with its own privacy policy. Hosting infrastructure may process ordinary HTTP request data; deployment-specific details belong in the published site's privacy notice.
