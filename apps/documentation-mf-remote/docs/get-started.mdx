Codegena generates TypeScript from OpenAPI and JSON Schema. Start with a specification, run the CLI, and inspect the generated files.

## Install

```bash
npm install @codegena/oapi3ts@4
```

## Generate TypeScript

```bash
npx oas3ts convert --schemaFilePath="./openapi.json" -o="./generated" --mode="separateFiles"
```

The specification is the source of truth. Keep generated output reproducible and make changes in the specification or generator configuration.

Continue with [Core features](/core-features) or [Extend](/extend).
