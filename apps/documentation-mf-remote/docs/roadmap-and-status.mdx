Codegena's generator, exploration tools, and integrations have different levels
of readiness. This page separates available features from planned work.

## Available

- **TypeScript generation:** Convert OpenAPI and JSON Schema through the CLI
  or browser Playground.
- **Output organisation:** Group related declarations into files and domain
  directories, with shared types and barrel exports.
- **Exploration:** Browse generated files, inspect dependencies, search source
  and output together, and follow warnings to their source locations.
- **Extensions:** Adapt output with EJS templates and AST-based visitors.

See [Get started](/) for a first conversion and [Core features](/core-features)
for the supported workflows.

## In development

- **IDE plugins:** Bring generation and exploration into VS Code and other IDEs.
- **Documentation:** Expand the usage guides and examples alongside the tools.

## Planned

- **Collaboration:** Shared reviews, decisions, and a record of precedents.
- **Additional languages:** Extend generation beyond TypeScript where there is
  demand and a suitable contributor or implementation.

These are development directions, without committed release dates. Use
[Contacts](/contacts) to discuss a requirement or [Contribute](/contribute) to
help with implementation.
