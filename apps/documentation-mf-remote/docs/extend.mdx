Use EJS templates to adjust emitted text or AST-based visitors for changes that need schema and declaration information.

## Choose an extension boundary

Keep schema interpretation separate from language-specific rendering. Reuse the transitive-node model rather than parsing the specification again.

See the [repository](https://github.com/koshevy/codegena) for package APIs and examples. Requests for additional target languages are welcome.
