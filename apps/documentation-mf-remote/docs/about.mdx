Codegena is a set of tools for deterministic code generation from OpenAPI and
JSON Schema. It combines a schema compiler, extensible generators, a CLI,
and browser tools for inspecting source specifications and generated output.

## Purpose

Routine generation should be predictable and inexpensive. Codegena keeps the
specification as the source of truth and makes the resulting files and their
dependencies easier to inspect, including in large APIs.

An AI assistant can operate the CLI using the supplied skills. Generation itself
does not require an AI model.
