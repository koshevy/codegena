Contact Alexander Koshevoy at [koshevy@gmail.com](mailto:koshevy@gmail.com)

## Bugs and contributions

Report reproducible bugs and discuss changes in the
[GitHub repository](https://github.com/koshevy/codegena).
Include the Codegena version, steps to reproduce, and a small specification
that demonstrates the problem. Remove private data before sharing it.

See [Contribute](/contribute) for the development workflow and
[Security](/security) for reporting security issues.
